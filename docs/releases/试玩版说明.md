# 霓虹 Roguelike Prototype — Windows 试玩版

## 启动

1. 将压缩包解压到任意文件夹。
2. 双击 `NeonRoguelike.exe` 开始游戏。

本试玩版不需要安装 Godot。请保留 EXE 所在文件夹结构；游戏资源已打包进 EXE。

## 操作

- `W` / `A` / `S` / `D`：移动
- 鼠标：瞄准
- 鼠标左键：射击
- `Space`：闪避
- `Tab`：显示 / 隐藏当前道具构筑
- `R`：重新开始
- 胜负结算后按 `Enter`：重新开始

普通房间清空后，从三件奖励中选择一件；通过三间房后挑战首领。

请记录你遇到的卡顿、看不懂的攻击提示、道具效果不明显之处，以及完整一局的结果和大致用时。
