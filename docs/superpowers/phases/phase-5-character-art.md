# 阶段五：首批角色像素美术接入

## 交付范围

- 将玩家、近战敌人、普通远程敌人、冲锋敌人、三连射敌人接入同一张原创角色精灵表。
- 关闭原有 Polygon2D 占位外观，保留原碰撞体、血条、攻击预警和行为。
- 角色材质使用最近邻纹理采样；色键 shader 在绘制时剔除绿幕底色。
- Boss 未包含在此精灵表，继续使用原占位造型。

## 素材处理记录

- 首次精灵表把棋盘格预览底纹烘焙进图像，且为 24-bit RGB，无 alpha 通道；不能直接作为透明精灵使用。
- 背景移除尝试仍保留棋盘格，因此生成纯绿色底素材。像素检查确认该素材为 24-bit RGB，没有 alpha 通道。
- 游戏内材质以纯绿色为键色并设置容差，渲染时丢弃底色像素；源素材保留在 `art/generated/`。

## 技术校验

- 首轮实机反馈发现敌人仍显示青 / 紫菱形占位图。根因：`Enemy._update_archetype_visuals()` 在场景隐藏占位节点后，又按敌人类型将近战 / 远程 Polygon2D 设为可见。
- 已修正为类型切换时始终隐藏全部旧占位 Polygon2D 与轮廓，只通过 `CharacterSprite.region_rect` 选择精灵表角色；攻击预警与血条保留。
- Godot 4.7.2 编辑器扫描、主场景运行检查：本次修正后待复验。
- 玩家实机视觉验收：待试玩反馈。

## 本轮试玩关注

1. 五种角色的大小、剪影和阵营颜色是否容易辨认。
2. 绿幕剔除后角色边缘是否干净，有无绿色残边或误删角色高光。
3. 玩家旋转瞄准时精灵方向是否自然。
4. Boss 占位外观与新角色之间的风格差是否可接受。
