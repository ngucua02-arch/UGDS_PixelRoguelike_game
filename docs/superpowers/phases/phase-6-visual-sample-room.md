# 阶段 6：视觉样板房

## 目标

让玩家在真实战斗中能明显感知像素美术接入，并保持角色、敌人、弹幕和攻击预警清楚。

## 完成内容

- 将原创霓虹工业风房间背景接入 `Room.tscn`，覆盖 1152×648 战斗视口；隐藏旧网格和几何底板，保留房间碰撞边界。
- 玩家精灵缩放从 0.10 调整为 0.13；普通敌人各原型精灵按其剪影调整至 0.095–0.13，不改碰撞尺寸和移动规则。
- 普通远程、三连射及冲锋攻击预警线降低透明度并将线宽从 3 调至 2，保留攻击方向辨识度。
- 保留当前已接入的角色色键 shader 和敌人类别颜色。
