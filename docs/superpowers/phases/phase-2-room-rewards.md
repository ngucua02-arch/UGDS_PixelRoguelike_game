# 阶段二：房间推进与道具选择试玩记录

## 范围与当前实现

- 三间固定普通战斗房依次配置为 2、3、4 名敌人；敌人包含近战与远程类型。
- 每间普通房清空后暂停玩家和房间战斗，清理玩家投射物，并从未持有的八件道具中抽取最多三件供玩家选择。
- 选择后应用一件局内道具并更新构筑摘要；前两次选择推进到下一间房，第三次选择进入 Boss 房。
- 玩家生命与已选道具随房间推进保留；奖励阶段通过 `damage_enabled` 关闭伤害入口。
- HUD 提供奖励选项和结算 UI。Task 14/15 的报告记载 Godot 编辑器扫描、主场景短时 headless 启动成功；静态截图用于检查当前视觉渲染。
