# 阶段七：首领战视觉切片

## 目标

在不改变战斗规则的前提下，让最终首领从占位形状变成可辨认的原创像素角色，并让现有两种攻击在战斗中更容易读懂。

## 完成内容

- 新增原创首领精灵 `art/generated/boss_neon_sentinel.png`。素材来自内置 ImageGen；尺寸 1312×1199，PNG 真透明背景，最近邻显示。
- 将精灵接入 `Boss.tscn`，隐藏原来的多边形身体与核心占位图；碰撞、生命、移动和伤害逻辑保持原值。
- 在现有 Boss 状态上加入精灵朝向、待机浮动、扇形攻击脉冲、冲撞蓄力压缩、冲刺拉伸、恢复晃动及受击闪白。
- 扇形预警增加四条淡洋红外侧路线，中心方向保留强提示；冲撞保留金色方向线并调到 3px，避免覆盖首领剪影。

## 验收依据

- 玩家在 2026-10-28 报告整体游玩可以、重开正常、暂时没有明显影响体验的问题，并同意进入垂直切片阶段。该试玩结果没有说明最终胜负和用时。
- 首领房预览中，角色轮廓在房间背景上可见；扇形预警外侧方向线及金色冲撞路线均清楚。
- Godot 4.7.2 headless editor import/scan 与主场景短时运行通过；`git diff --check` 通过。以上技术和预览检查不能替代完整流程试玩。

## 玩家试玩关注

1. 首领体量是否足够醒目、像素细节是否与房间和小型敌人协调。
2. 扇形预警是否能让人预判弹幕覆盖范围。
3. 冲撞预警方向是否清楚、是否仍有足够时间躲开。
4. 受击闪白、蓄力与恢复姿态是否看得出，但不会遮挡弹幕或 Boss 生命条。

## 玩家验收

- 玩家反馈：首领醒目，扇形与冲撞预警好判断，受击和蓄力动作清楚。
- 结论：首领战视觉切片通过玩家验收。未收到机制、数值或难度调整要求。
- HUD 整合试玩也已通过：构筑摘要不会遮挡敌人或弹幕；Tab 显示 / 隐藏顺手；奖励选择时道具详情方便比较。
- 玩家确认垂直切片通过，项目转入 Windows 试玩包发布准备。
